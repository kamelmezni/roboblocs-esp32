# Code de conduite

RoboBlocs est utilisé par des élèves, y compris des mineurs. Le projet doit rester un espace **bienveillant et sûr**.

## Nos engagements
- Être respectueux et patient, surtout avec les débutants.
- Critiquer le code et les idées, jamais les personnes.
- Accepter les retours constructifs.

## Comportements inacceptables
- Insultes, harcèlement, discrimination, propos haineux ou sexuels.
- Publication d'informations personnelles d'autrui (surtout d'élèves) sans autorisation.
- Spam, publicité, contenu dangereux ou illégal.

## Application
Les responsables peuvent modifier, masquer ou supprimer tout contenu contraire à ce code, et bannir son auteur.
