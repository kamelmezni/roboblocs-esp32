# Feuille de route

Ce document liste les idées pour RoboBlocs. L'ordre n'est pas une promesse : les priorités suivent les besoins des classes.

## En cours
- [ ] **Version hors ligne (offline)** : IDE utilisable sans internet.
- [ ] Stabilisation de la **phase de test** (retours d'élèves et d'enseignants).

## Prochainement
- [ ] Nouveaux blocs : écran OLED, capteur DHT11/DHT22, NeoPixel, moteur DC.
- [ ] Davantage d'exemples de **tableaux de bord Wi-Fi** (température, commande de servo).
- [ ] Interface en **arabe** et en **anglais**.
- [ ] Fiches pédagogiques imprimables (schéma de montage + défis) pour chaque exemple.

## Idées
- [ ] Simulation des blocs dans le navigateur avant envoi à la carte.
- [ ] Prise en charge d'autres cartes (ESP32-S3, Raspberry Pi Pico W).
- [ ] Mode « défi » avec auto-évaluation.
- [ ] Intégration de modèles d'IA légers (TinyML) pour le club IoT et IA.

Proposez une idée via une *issue* « Proposition de fonctionnalité ».
