Mon IDE : RoboBlocs ESP32

Un environnement de programmation par blocs conçu pour mes élèves : on assemble des blocs, le code Python est généré automatiquement et envoyé à la carte ESP32 en un clic. Le projet est open source : le code est disponible sur GitHub.

IDE gratuitESP32MicroPython

RoboBlocs ESP32

Connexion USB directe depuis le navigateur, génération automatique du code Python, sauvegarde des projets et enregistrement du programme sur la carte.

⚠️ Avant de commencer : installer le pilote CP210x_Windows_Drivers et formater la carte avec Thonny pour qu'elle reçoive le code MicroPython.

Lancer l'IDEDécouvrir et comprendreCode source GitHub

Ce que vous pouvez faire

  • Connecter la carte ESP32 par câble USB
  • Voir le code Python généré en direct
  • Envoyer et lancer le programme, ou l'arrêter
  • Mettre le programme sur la carte (démarrage automatique)
  • Enregistrer et rouvrir ses projets
  • 13 exemples prêts à charger, dont le radar de recul avec tableau de bord Wi-Fi, QR code Wi-Fi, Bluetooth
