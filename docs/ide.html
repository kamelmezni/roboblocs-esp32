📖 Guide d'utilisation

1. Préparer la carte (une seule fois)

  1. Installer le pilote CP210x : silabs.com.
  2. Installer Thonny.
  3. Brancher l'ESP32 avec un câble USB qui transmet les données.
  4. Thonny : Exécuter → Configurer l'interpréteur → MicroPython (ESP32) → Installer ou mettre à jour MicroPython.
  5. Si l'installation reste sur « Connecting… », maintenir le bouton BOOT de la carte.
  6. Fermer Thonny : un seul logiciel peut utiliser le port à la fois.

2. Utiliser RoboBlocs

  1. Ouvrir l'IDE avec Chrome ou Edge.
  2. 🔌 Connecter la carte, choisir le port USB (CP210x).
  3. Assembler les blocs ou charger un modèle avec 📚 Exemples.
  4. ▶ Envoyer et lancer ; ■ Arrêter pour stopper.
  5. 📲 Mettre sur la carte : le programme démarre tout seul à chaque mise sous tension.
  6. 💾 Enregistrer le projet / 📁 Ouvrir un projet pour retrouver son travail (fichier .json).

3. Exemple : radar de recul avec tableau de bord Wi-Fi

  • HC-SR04 : Trig → broche 23, Echo → broche 22 (avec diviseur de tension), VCC → 5V (VIN), GND → GND.
  • LED : broche 21 via une résistance de 220 Ω. Buzzer actif : broche 19.
  • Charger l'exemple dans 📚 Exemples, puis Envoyer et lancer.
  • Se connecter au Wi-Fi ESP32-Radar (mot de passe d'exemple 12345678, à changer) et ouvrir http://192.168.4.1.
  • Sous 10 cm : message d'alerte, ampoule rouge, LED et bips.

4. Dépannage

  • La carte n'apparaît pas : pilote CP210x manquant, câble « charge seulement », ou Thonny encore ouvert.
  • Bouton Connecter sans effet : utiliser Chrome ou Edge, pas Firefox ni Safari.
  • Erreur à l'envoi : vérifier que MicroPython est installé sur la carte (étape 1).
  • Le Wi-Fi n'apparaît pas : attendre quelques secondes après le lancement, puis relancer la carte (bouton EN).
