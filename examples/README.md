# Projets partagés

Déposez ici vos projets RoboBlocs exportés (**💾 Enregistrer le projet** → fichier `.json`).

Convention de nom : `categorie-titre-court.json`, par exemple `capteurs-distance-oled.json`.
Ajoutez à côté un `.md` du même nom : objectif, matériel, schéma de câblage, captures d'écran.
Ne mettez **aucun mot de passe Wi-Fi personnel** dans un projet partagé.
