# Sécurité

## Signaler une vulnérabilité
Merci de **ne pas** ouvrir d'issue publique pour une faille de sécurité.
Écrivez à <kamel.mezni@gmail.com> avec une description, les étapes pour reproduire et l'impact estimé.
Un accusé de réception est envoyé dès que possible.

## Bonnes pratiques pour les classes
- Les exemples Wi-Fi utilisent un mot de passe d'exemple (`12345678`) : **changez-le** pour tout usage hors salle de classe.
- Ne laissez pas une carte avec un tableau de bord ou un serveur web accessible sur un réseau public.
- Ne mettez jamais vos identifiants Wi-Fi personnels dans un projet que vous partagez ou publiez sur GitHub.
